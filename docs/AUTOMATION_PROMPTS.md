# ChatGPT 定时任务规范

## 南都柏林住房销售

每天收集并核实 Affordable Purchase、开发商新房和私人二手出售房，生成正式 HTML 邮件。保留 Google 地图、编号、颜色图例、原始详情链接、价格、户型、状态及必要申请条件。已关闭或 Sale Agreed 项目必须进入 Watchlist，不得当作可立即购买项目。

## 南都柏林住房租赁

每周收集并核实私人整租和 Cost Rental。Daft.ie 为固定来源，并补充其他可靠平台。优先总月租较低的一室一厅；公寓与 House 均可，位置稍远但价格明显更低的房源也可列出。Cost Rental 展示公开资格、申请状态和官方链接。邮件不得出现任何个人姓名、工作单位或收入信息。
