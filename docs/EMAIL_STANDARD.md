# 南都柏林住房邮件统一标准

销售和租赁邮件必须使用同一套结构和质量门槛。任何一项校验失败，邮件都不得发送残缺版本。

## 固定版式

1. 标题与核验时间。
2. 三个摘要卡片：`本期条目`、`独立地图位置`、`当前重点`。
3. Google Static Maps 总览图片，邮件正文中直接可见，最大宽度 640px。
4. 地图点位使用 `1–9、A–Z`，同一项目不同户型共用一个点位。
5. 地图下方显示颜色图例和编号地址清单。
6. 下方详情卡片必须使用与地图相同的编号。
7. 末尾显示状态与核验免责声明。

## 地图要求

- HTML 必须同时包含 `<img>` 和 `maps.googleapis.com/maps/api/staticmap`。
- 不允许用普通 Google Maps 链接、路线链接或纯文字地点列表替代总览图。
- Google Static Maps 获取失败时，发送流程必须失败，不得静默降级。
- API Key 仅通过环境变量或 GitHub Actions Secret 提供，不得写入仓库。

## 链接要求

所有主要按钮必须直达具体项目或具体房源详情页。

以下链接不合格：

- 网站首页；
- 搜索结果页；
- 地区或城市列表页；
- 分类页；
- 需要用户进入网站后再次搜索项目的中间页。

例如：

- 合格：`https://affordablehomes.ie/buy/foothills/`
- 不合格：`https://affordablehomes.ie/`

无法确认稳定详情页的项目不得进入主要推荐区，应放入“直达链接待核实”区域。

## 销售颜色

- 蓝色：Affordable Purchase
- 紫色：开发商新房
- 红色：私人二手 House
- 灰色：待核实、已关闭或 Sale Agreed

## 租赁颜色

- 橙色：私人整租
- 绿色：Cost Rental

## 发送前自动校验

发送模式会执行以下检查：

- Static Maps 图片存在；
- 三个摘要卡片存在；
- 地图没有进入错误回退状态；
- 所有主要链接不是首页或明显的搜索／分类页面；
- 地图编号与详情卡片编号来自同一套顺序。

本地只生成 HTML 时可以用于调试；正式 `--send` 发送时必须通过全部校验。
