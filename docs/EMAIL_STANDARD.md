# 南都柏林住房邮件统一标准

销售和租赁邮件统一以 **2026-07-24 09:13（Europe/Dublin）发送的销售邮件** 为版式基准。任何后续修改都不得改变这套主要结构。

## 标准主题

- 销售：`南都柏林住房销售｜YYYY-MM-DD`
- 租赁：`南都柏林住房租赁｜YYYY-MM-DD`
- 定时发送不得添加“测试”“补正版”“修正版”等临时后缀。
- 每次计划运行最多发送一封正式邮件。

## 固定顺序

1. 邮件标题。
2. `更新日期` 与 `信息核验`。
3. 单段 `本期重点`，概括本期申请开放、项目状态、价格和供应变化。
4. 三个摘要卡片：`本期条目`、`独立地图位置`、`当前重点`。
5. `所有房源位置总览` 或 `所有出租位置总览`。
6. 一个可直接点击的 Google Maps 总览入口。
7. 颜色图例。
8. 使用 `1–9、A–Z` 的紧凑编号项目清单。
9. 按类别展示房源详情；详情编号必须与地图清单一致。
10. 每个当前有效项目必须包含具体详情页链接和独立 `Google Maps` 链接。
11. Watchlist。
12. 状态与核验免责声明。

## Google Maps 标准

基准邮件中的地图不是正文图片，而是以下三部分：

- `南都柏林住房销售位置总览`／`南都柏林住房租赁位置总览` Google Maps 按钮；
- 按编号排列的位置清单；
- 每套当前有效房源下方的独立 `Google Maps` 链接。

必须使用 Google Maps Search URL：

`https://www.google.com/maps/search/?api=1&query=...`

以下做法不再使用：

- Google Static Maps 图片；
- CID 内嵌地图图片；
- 依赖邮件客户端加载远程地图图片；
- 只有地点文字、没有可点击 Google Maps 入口；
- 只有总览入口、但具体房源没有独立地图链接。

采用链接式地图是为了与 09:13 基准邮件一致，并避免 Gmail 或其他邮件客户端拦截、隐藏或代理图片后造成“地图丢失”。

## 编号规则

- 编号使用 `1–9、A–Z`。
- 同一地址或同一项目的多个户型共用一个编号。
- 总览清单和详情卡片使用同一套编号。
- `独立地图位置` 显示去重后的地点数量，不是房源条目总数。

## 销售分类与颜色

- 蓝色：Affordable Purchase
- 紫色：开发商新房
- 红色：私人二手 House
- 灰色：待核实、已关闭或 Sale Agreed

销售类别标题固定为：

- `Affordable Purchase`
- `开发商新房`
- `二手出售房 · 价格优先`
- `Watchlist`

## 租赁分类与颜色

- 橙色：私人整租
- 绿色：Cost Rental

租赁邮件沿用同一顶部结构、地图总览结构和编号规则。

## 链接要求

主要房源按钮必须直达具体项目或具体房源详情页。

以下链接不合格：

- 网站首页；
- 搜索结果页；
- 地区或城市列表页；
- 分类页；
- 需要用户进入网站后再次搜索项目的中间页。

例如：

- 合格：`https://affordablehomes.ie/buy/foothills/`
- 不合格：`https://affordablehomes.ie/`

无法确认稳定详情页的项目不得用搜索页代替，应明确标记为“直达详情页待核实”。

## 发送前自动校验

正式发送会检查：

- `更新日期` 与 `信息核验` 存在；
- `本期重点` 存在；
- 三个摘要字段存在；
- Google Maps 总览入口存在；
- 至少一个房源独立 `Google Maps` 链接存在；
- 编号清单存在；
- 没有重新引入 Static Maps 或 CID 地图图片；
- 主要房源链接不是首页、搜索页或分类页。

本地生成 HTML 可以用于调试；正式发送前必须通过全部校验。
