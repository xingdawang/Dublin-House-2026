# 南都柏林住房邮件统一标准

销售和租赁邮件必须使用同一套结构和质量门槛。任何一项校验失败，邮件都不得发送残缺版本。

## 邮件主题

- 销售：`南都柏林住房销售｜YYYY-MM-DD`
- 租赁：`南都柏林住房租赁｜YYYY-MM-DD`
- 定时发送不得添加“测试”“补正版”“修正版”等临时后缀。
- 每次计划运行最多发送一封正式邮件；校验失败时直接停止，不得连续补发不同版本。

## 固定版式

1. 标题与核验时间。
2. 三个摘要卡片：`本期条目`、`独立地图位置`、`当前重点`。
3. Google Static Maps 总览图片，作为 CID 内嵌图片随邮件发送，正文中直接可见，最大宽度 640px。
4. 地图点位使用 `1–9、A–Z`，同一项目不同户型共用一个点位。
5. 地图下方显示颜色图例和编号地址清单。
6. 下方详情卡片必须使用与地图相同的编号。
7. 末尾显示状态与核验免责声明。
8. 不发送普通文件附件；地图仅作为邮件正文内嵌图片存在。

## 地图要求

- Google Static Maps 图片必须先成功生成并通过图片响应校验。
- 正式邮件 HTML 必须同时包含 `<img>`、正确的地图 `alt` 文本和对应的 `cid:` 地址。
- 不允许用普通 Google Maps 链接、路线链接、纯文字地点列表或远程 Static Maps URL 替代内嵌总览图。
- Google Static Maps 获取失败、CID 图片缺失或地图进入错误回退状态时，发送流程必须失败，不得静默降级。
- SMTP 发送器必须再次核对 HTML 中引用的每个 CID 都有对应图片文件；图片必须存在、非空并能被识别为有效图片。不得因为文件缺失而跳过附件后继续发信。
- API Key 仅通过环境变量或 GitHub Actions Secret 提供，不得写入仓库，也不得出现在最终邮件 HTML 中。

## 链接要求

所有主要按钮必须直达具体项目或具体房源详情页。

以下链接不合格：

- 网站首页；
- 搜索结果页；
- 地区或城市列表页；
- 分类页；
- 需要用户进入网站后再次搜索项目的中间页。

例如：

- 合格：`https://affordablehomes.ie/buy/foothills/`
- 不合格：`https://affordablehomes.ie/`

无法确认稳定详情页的项目不得进入主要推荐区，应放入“直达链接待核实”区域。

## 销售颜色

- 蓝色：Affordable Purchase
- 紫色：开发商新房
- 红色：私人二手 House
- 灰色：待核实、已关闭或 Sale Agreed

## 租赁颜色

- 橙色：私人整租
- 绿色：Cost Rental

## 发送前自动校验

发送模式会执行以下检查：

- Static Maps 图片已经成功下载；
- 邮件使用 CID 内嵌地图，而不是远程图片或纯链接；
- HTML 中的 CID 与实际随信附加的图片一一对应；
- CID 图片文件存在、非空且为有效图片；
- 三个摘要卡片存在；
- 地图没有进入错误回退状态；
- 所有主要链接不是首页或明显的搜索／分类页面；
- 地图编号与详情卡片编号来自同一套顺序；
- 单次计划运行不会产生多封补正版邮件。

本地只生成 HTML 时可以用于调试；正式 `--send` 发送时必须通过全部校验。
